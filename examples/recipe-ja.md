# 肉じゃが

ほくほくのじゃがいもに、甘辛い味がしみ込んだ家庭料理の定番です。煮込む時間はほんの少し。作りたてはもちろん、一晩おいて味をなじませるともっとおいしくなります。

## 基本情報

| 項目 | 内容 |
|---|---|
| 分量 | 4 人分 |
| 準備時間 | 15 分 |
| 調理時間 | 25 分 |
| 難易度 | かんたん |

## 材料

| 材料 | 分量 |
|---|---|
| 牛薄切り肉 | 200 g |
| じゃがいも | 3 個（約 450 g） |
| 玉ねぎ | 1 個 |
| にんじん | 1 本 |
| しらたき | 1 袋（150 g） |
| さやいんげん | 6 本 |
| サラダ油 | 大さじ 1 |
| だし汁 | 300 ml |
| 砂糖 | 大さじ 2 |
| しょうゆ | 大さじ 3 |
| みりん | 大さじ 2 |
| 酒 | 大さじ 2 |

## 作り方

1. じゃがいもは皮をむいて一口大に切り、水に 5 分さらす。玉ねぎはくし形、にんじんは乱切りにする。
2. しらたきは食べやすい長さに切り、さっとゆでてざるにあげる。さやいんげんは筋を取って半分に切る。
3. 鍋にサラダ油を熱し、牛肉を色が変わるまで炒める。
4. 玉ねぎ、にんじん、じゃがいも、しらたきを加えて 2 分ほど炒める。
5. だし汁、砂糖、酒、みりんを加えて煮立て、アクを取る。
6. 落としぶたをして、弱めの中火で 10 分煮る。
7. しょうゆを加えてさらに 10 分煮る。さやいんげんを加えて 2 分ほど煮たら完成。

## ポイント

> **コツ：** 砂糖を先に、しょうゆは後に入れると味がよくしみ込みます。
>
> 煮崩れが心配なときは、じゃがいもを大きめに切り、混ぜすぎないようにしましょう。

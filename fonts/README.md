# fonts/

このフォルダは、`just fonts` で IPAex フォントをダウンロードして置く場所です。

- IPAexゴシック: `ipaexg.ttf`
- IPAex明朝: `ipaexm.ttf`

入手元: https://moji.or.jp/wp-content/ipafont/IPAexfont/IPAexfont00401.zip

フォントの利用・再配布は IPA フォントライセンス v1.0（`IPA_Font_License_Agreement_v1.0.txt`）に従ってください。

フォントのバイナリとライセンス文書などのダウンロード物は git 管理しません（`.gitignore` で `README.md` 以外を無視しています）。
